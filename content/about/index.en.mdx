## What OronBox is

OronBox is a community-maintained, third-party, open-source wearable-device management tool. It connects VelaOS / Xiaomi and ZeppOS devices, shows device information, manages apps and watchfaces, installs community resources, and supports plugin extensions.

OronBox is unrelated to device manufacturers and is not endorsed or authorized by them. It is also independent of third-party platforms including BandBBS, AstroBox, GitHub, and Cloudflare.

## Architecture

| Component | Description |
| --- | --- |
| Client | Flutter app for Windows / macOS / Linux / Android / Web (no iOS) |
| Server | Go implementation providing accounts, the resource registry, review, and publication; self-hostable |
| CLI | Manage devices, install resources, access community sources, and drive background tasks without the GUI |

The official online service is separate from self-hosted OronBox Server instances.
