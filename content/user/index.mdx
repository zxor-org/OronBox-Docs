OronBox 是社区维护的开源可穿戴设备管理工具

不需要官方客户端，就可以连接和管理 **VelaOS（小米 / 红米系）** 与 **ZeppOS（Amazfit 等）** 设备，查看设备状态、安装表盘与应用、同步音乐和录音、更新固件

客户端与服务端代码均开源（AGPL-3.0）：

- 客户端仓库：[zxor-org/OronBox](https://github.com/zxor-org/OronBox)
- 服务端仓库：[zxor-org/OronBox-Server](https://github.com/zxor-org/OronBox-Server)

## 界面导航

应用有五个主页面（标签）：

| 标签 | 用途 |
| --- | --- |
| 首页 | 每日精选、每日推荐、最新动态与资讯 |
| 探索 | 资源库：搜索、浏览并安装表盘、快应用等资源 |
| 设备 | 已配对设备、连接与设备管理 |
| 插件 | 安装与管理插件，查看插件市场 |
| 设置 | 账号、外观、下载与安装行为、反馈等 |

## 开始使用

1. [安装 OronBox](/user/install)，完成首次启动引导
2. [连接你的设备](/user/connect)，输入认证密钥完成配对
3. 到[探索页](/user/resources)找表盘、应用安装到设备

## 平台支持

| 平台 | 状态 | 要求 |
| --- | --- | --- |
| Windows | ✅ 支持 | Windows 10（64 位）及以上 |
| macOS | ✅ 支持 | macOS 10.15 及以上（Intel 与 Apple Silicon） |
| Linux | ✅ 支持 | 需要图形桌面环境，发行版不限 |
| Android | ✅ 支持 | Android 7.0 及以上 |
| Web | ✅ 支持 | Chrome / Edge |
| iOS | ❌ 不支持 | 暂无计划 |
