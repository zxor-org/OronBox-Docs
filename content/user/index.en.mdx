OronBox is a community-maintained open-source wearable device manager for **VelaOS (Xiaomi / Redmi)** and **ZeppOS (Amazfit etc.)** devices. Without the official client you can check device status, install watchfaces and apps, sync music and recordings, and update firmware.

Both the client and server are open source (AGPL-3.0):

- Client repository: [zxor-org/OronBox](https://github.com/zxor-org/OronBox)
- Server repository: [zxor-org/OronBox-Server](https://github.com/zxor-org/OronBox-Server)

## Navigation

The app has five tabs:

| Tab | Purpose |
| --- | --- |
| Home | Daily featured picks, daily recommendations, recent updates and news |
| Explore | Resource library: search, browse and install watchfaces, quick apps etc. |
| Devices | Paired devices, connecting and device management |
| Plugins | Install and manage plugins, browse the plugin market |
| Settings | Accounts, appearance, download and install behavior, feedback |

## Quick start

1. [Install OronBox](/en/user/install) and finish the first-run wizard
2. [Connect your device](/en/user/connect) and pair it with its authkey
3. Open [Explore](/en/user/resources) to find watchfaces and apps to install

## Platform support

| Platform | Status | Requirements |
| --- | --- | --- |
| Windows | ✅ Supported | Windows 10 (64-bit) or newer |
| macOS | ✅ Supported | macOS 10.15 or newer (Intel and Apple Silicon) |
| Linux | ✅ Supported | A graphical desktop session; any distribution |
| Android | ✅ Supported | Android 7.0 or newer |
| Web | ✅ Supported | Chrome / Edge |
| iOS | ❌ Not supported | No plans announced |
