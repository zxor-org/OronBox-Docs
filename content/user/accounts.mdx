---
title: 账号管理
description: 米坛、小米、华米、GitHub 四种账号的用途与登录方式
---

账号入口在「设置 → 账号与授权」

OronBox 支持四种账号，各自用途不同：

| 账号 | 登录方式 | 用途 |
| --- | --- | --- |
| 米坛 BandBBS | 浏览器授权 | 访问米坛资源、参与评论、使用创作者中心 |
| 小米 | 用户名 + 密码 | 同步已绑定的小米设备（含认证密钥） |
| 华米 | 用户名 + 密码 | 访问华米应用商店资源 |
| GitHub | 浏览器授权（需先登录米坛） | 以自己的账号发布 AstroBox 资源 |

首次启动引导的第 3 步也可以选登录，可以跳过，之后随时在设置里登录

## 米坛 BandBBS

点击「登录 BandBBS」后会在浏览器中完成授权，登录成功后：

- 可以访问米坛社区资源，参与评论
- 可以查询**已购资源**并安装已购的付费资源（米坛账号页 → 已购资源 → 输入资源 ID → 查询）
- 可以使用[创作者中心](/creator)发布资源

会话过期后需要重新登录

## 小米

在登录框输入账号与密码，登录在客户端本地完成（不会发送给第三方）

- 「登录并同步」会同步你账号下已绑定的小米设备，**只有带认证密钥的设备会被导入**，之后可以直接连接
- 如果账号开启了**两步验证（2FA）**，应用会在内嵌的验证窗口中打开验证页面，完成验证后继续登录
- **Web 端不支持小米两步验证**，开启 2FA 的账号在浏览器里无法登录
- 勾选「记住账号密码」后，账密才会保存在本机

## 华米

输入账号与密码登录，保存访问 Zepp 商店所需的凭据，用于华米应用商店资源

## GitHub

用于以自己的 GitHub 账号发布 AstroBox 资源：

- **必须先登录米坛账号**：未登录米坛时，GitHub 条目显示「登录米坛账号后可连接」，GitHub 登录依赖米坛会话
- 点击连接后在浏览器中完成 GitHub 授权，完成后应用自动继续

## 常见错误

- 「小米账号或密码错误」：用户名或密码不对
- 「小米账号二次验证未完成，请重新登录」：两步验证流程中断，重新登录并完成验证
- 「OronBox 登录已过期，请重新登录米坛账号」：米坛会话过期，重新登录
