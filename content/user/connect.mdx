## 支持的设备

客户端按蓝牙名自动识别设备：

**小米 / 红米系（VelaOS）**：小米手环 8 Pro、9、9 Pro、10、10 Pro；小米 Watch S1 Pro、S3、S4、S5；Redmi Watch 4、5、5 eSIM、6

**ZeppOS 系**：Amazfit Active、Balance、Band 7、Bip 5/6、Cheetah、GTR 3/4、GTS 3/4、T-Rex 2/3/Ultra、Helio Ring 等

注意：**小米手环 7（Xiaomi Smart Band 7）也属于 ZeppOS 设备**，按 ZeppOS 方式连接

蓝牙名未命中任何已知型号时会显示「未识别设备」，仍可以手动连接尝试

## 连接方式

- **小米 / 红米系**：通过经典蓝牙（SPP）连接；连接前需要在设备端开启「连接新手机」模式（一般在手环/手表的蓝牙设置里）
- **ZeppOS 系**：通过低功耗蓝牙（BLE）连接，不需要系统蓝牙配对
- **Web 端**：小米系设备通过 Web Serial（浏览器串口）连接，ZeppOS 设备通过 Web Bluetooth 连接

## 首次连接

1. 打开「设备」标签页，点击「扫描并添加」
2. 等待扫描结果（默认 15 秒后自动停止；没扫到可以再扫一次）
3. 在「发现设备」列表里点击你的设备
4. 输入设备的**认证密钥（authkey）**，点击连接
5. 等待连接完成，界面依次显示：正在准备连接 → 正在建立连接 → 正在初始化设备协议 → 正在认证设备 → 正在读取设备信息
6. 连接成功后设备会出现在「已配对设备」列表，之后点一下就能直接连

> 如果设备之前被官方客户端或其他工具连接过，请先在那里断开——蓝牙设备同一时间通常只能被一个连接占用

## 认证密钥（authkey）

authkey 是设备的认证密钥，两类设备连接时都要用它完成验证

- **小米系**：登录小米账号后可以同步已绑定设备的 authkey（设置 → 账号 → 小米账号 →「登录并同步」），也可以手动输入
- **ZeppOS 系**：authkey 是 32 位十六进制字符串；如果设备还在用默认密钥，可以留空

authkey 保存在本地（Web 端保存在当前浏览器），未做加密，请不要在公共设备上输入

## Web Serial（Web 端连接小米系设备）

1. 在「设备」页点击「通过 Web Serial 连接」
2. 输入认证密钥，并在浏览器弹出的串口选择窗口中选择设备对应的串口
3. 已保存的设备与认证密钥会保留在当前浏览器中；换浏览器或清除站点数据后需要重新连接

## 自动回连

「设置 → 连接与下载 → 自动回连」开启后，启动应用时会自动连接上次配对的设备（默认关闭；Web 端不支持）

## 连接失败排查

- 「蓝牙不可用，请检查蓝牙是否已开启，并确认系统权限已允许 OronBox 使用蓝牙」：蓝牙没开或没授权；macOS 首次启动需要在系统弹窗中允许蓝牙
- 「连接失败，请确认蓝牙权限已授予且蓝牙已开启、设备在附近、未被其他工具或设备占用，并在设备端开启「连接新手机」模式后重试」：设备没找到或设备忙，逐项检查上面列的条件
- 「蓝牙连接已断开，请重新连接设备」：连接中途断开，重新连接
- 「未发现可用的传输端点，请先完成系统蓝牙配对，然后重新扫描」：先在系统蓝牙设置里完成配对，再回到应用扫描
