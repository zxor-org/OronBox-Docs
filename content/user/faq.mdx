## 连接与蓝牙

**提示「蓝牙不可用，请检查蓝牙是否已开启，并确认系统权限已允许 OronBox 使用蓝牙」**

蓝牙没开或系统没授权

开启蓝牙并在系统设置中允许 OronBox 使用蓝牙；macOS 首次启动需要在弹窗中允许蓝牙权限

**提示「连接失败，请确认蓝牙权限已授予且蓝牙已开启、设备在附近、未被其他工具或设备占用，并在设备端开启“连接新手机”模式后重试」**

连接超时、被拒绝或设备忙时都会提示这条

依次检查：蓝牙权限与开关、设备电量与距离、是否被其他应用或设备占用（比如官方客户端）、设备端是否开启了「连接新手机」模式

**提示「蓝牙连接已断开，请重新连接设备」**

连接中途断开，重新连接即可

**提示「操作超时，请确认设备仍在附近并重试」**

操作在超时时间内没完成，确认设备在附近且可连接后重试

**提示「设备尚未准备好，请先连接并完成认证」**

目标操作需要设备已连接且完成认证

**提示「未找到需要的 BLE 通道，请重新连接设备或检查设备是否支持该功能」**

设备没暴露协议需要的蓝牙通道，或连接状态异常

重新连接；如果设备本身不支持该功能，则不可用

**提示「未发现可用的 \{传输方式\} 端点，请先完成系统蓝牙配对，然后重新扫描」**

先在系统蓝牙设置里完成配对，再回到应用重新扫描

## Web 端

**提示「当前浏览器不支持 Web Serial，请使用 Chrome / Edge 等支持 Web Serial 的浏览器」**

Web 端连接小米系设备依赖 Web Serial，请用 Chrome / Edge

设备与认证密钥保存在当前浏览器，换浏览器或清除站点数据后需要重新连接

**Web 端无法连接 ZeppOS 设备？**

ZeppOS 设备在 Web 端通过 Web Bluetooth 连接，需要浏览器与系统同时支持

## 账号

**提示「小米账号或密码错误」**

用户名或密码不对

**提示「小米账号二次验证未完成，请重新登录」**

两步验证流程中断，重新登录并在应用内验证窗口完成验证；Web 端不支持小米两步验证

**提示「OronBox 登录已过期，请重新登录米坛账号」**

米坛会话过期或被撤销，重新登录

GitHub 连接等依赖米坛登录的功能也会受影响

**提示「请先在设置中登录米坛账号」 / 「请先在设置中登录华米账号」**

对应功能需要该账号，先在「设置 → 账号与授权」登录

## 资源与安装

**提示「不支持或无法识别的文件类型」**

本地文件无法识别为受支持的资源类型

应用按文件内容而非扩展名判断，请确认文件是完整的资源包

**安装时提示平台不匹配，可以强制安装吗？**

会弹出警告并带 3 秒倒计时，倒计时结束后手动点击「强制安装」才会执行

强行安装可能引发不可预知的问题，仅在确认文件来源与设备匹配时使用

ZeppOS 资源装到 VelaOS 设备（或反过来）通常都会失败

**提示「无法连接服务，请检查网络后重试」 / 「服务暂时不可用，请稍后重试」**

前者是网络问题（离线、服务器不可达），后者是服务器暂时不可用

检查网络或稍后再试

**提示「操作过于频繁，请稍后重试」**

触发了限流，稍等片刻再操作

**提示「所选文件过大」**

文件超出大小限制

**提示「证书校验失败，如果正在使用代理，请关闭对本应用的 HTTPS 接管，或确认系统信任其证书」**

通常出现在使用了 HTTPS 拦截代理时

关闭代理对本应用的 HTTPS 接管，或确认系统信任相应证书

## 固件

**ZeppOS 设备显示「暂未接入此类设备的在线固件源」**

ZeppOS 的在线固件源尚未实现，检查更新不可用

ZeppOS 设备只能通过「本地固件安装」刷写；小米 / Vela 设备可以使用在线固件源检查更新（见[固件管理](./firmware)）

## 通用

**提示「操作失败：\{详细原因\}」**

未匹配到已知错误类型的兜底提示

可以到「设置 → 运行日志」查看日志排查，或通过「意见反馈」提交工单
