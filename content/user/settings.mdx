「设置」标签页按分类组织：

| 分类 | 内容 |
| --- | --- |
| 账号与授权 | 米坛 / 小米 / 华米 / GitHub 账号，见[账号](./accounts) |
| 外观与导航 | 语言、主题、导航位置、纯净模式 |
| 连接与下载 | 自动回连、下载节点、安装分包间隔 |
| 队列 | 自动安装、是否保留已完成的安装队列项 |
| 支持与信息 | 反馈工单、关于、许可、致谢、官网 |
| 高级设置 | 关闭按钮行为、重新引导、开发工具 |

## 外观

- **语言**：切换应用显示语言
- **主题模式**：跟随系统 / 浅色 / 深色 / OLED 深色
- **动态取色**：使用系统主题色调整配色
- **配色方案**：粉色、紫色、青色、绿色、红色、琥珀色
- **导航位置**：宽屏下侧边标签的位置（置底 / 居中 / 分离）

## 纯净模式（功能开关）

「设置 → 外观与导航 → 纯净模式」可以逐个开关功能：

- 主导航：插件主入口、探索主入口、消息箱
- 首页板块：Banner 轮播、编辑分区、首页信息流、公告弹窗
- 资源源：OronBox 源、米坛源、AstroBox 源、华米应用商店
- 社区能力：评论区、创作者中心、米坛登录、GitHub 登录

关闭后对应内容不再显示

## 连接与下载

- **自动回连**：启动时自动连接上次配对的设备（默认关闭；Web 端不支持）
- **GitHub 源 CDN**：获取访问托管在 GitHub 上的社区索引所用的节点（首次启动引导里会自动测速选择）
- **分包间隔**：安装时蓝牙分包发送的延迟，一般不需要调整

## 队列

- **自动安装**：下载完成后自动开始安装（默认开启）
- **不清除安装队列**：保留已完成的安装队列项

## 反馈工单

「设置 → 支持与信息 → 意见反馈」可以提交问题或建议：

- 填写**标题**和**意见或问题**，提交后成为一张工单
- 状态：待处理 / 处理中 / 已答复 / 已解决 / 已驳回 / 已关闭
- 可以查看处理结论并继续回复（已关闭的工单不能回复）

## 运行日志

「设置 → 运行日志」可以查看、导出和管理日志，也可以拉取设备日志（小米系）

> 日志可能包含登录凭证等敏感信息，**不要随意分享给除官方维护者以外的人**

## 关于

- 关于软件：版本、更新日志、开发团队、构建信息
- 免责声明：用户协议与责任声明
- 官方网站：[oronbox.zxor.org](https://oronbox.zxor.org)
- QQ 群：加入社区群聊
- 开放源代码许可与特别鸣谢

## 高级设置

- **关闭按钮行为**：每次询问 / 直接退出 / 最小化到托盘
- **重新引导**：再次查看首次启动的欢迎向导
- **DevTools**：开启独立的调试窗口
- **神秘工具 → 计算解锁码**：输入设备上显示的 MAC 地址和序列号生成小米穿戴解锁码；解锁可能导致保修失效或数据丢失，使用前会有风险警告
