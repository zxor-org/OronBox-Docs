设备连接成功后，「设备」页会显示当前设备，并提供一系列管理功能

多台设备时可以用「切换设备」在已配对设备之间切换

## 设备概览

设备页顶部显示当前连接状态、电量、充电状态与上次充电时间

## 基础功能

| 功能 | 说明 |
| --- | --- |
| 安装应用 | 从本地文件安装第三方应用 |
| 安装表盘 | 从本地文件安装表盘 |
| 固件更新 | 检查更新或安装本地固件，见[固件管理](./firmware) |
| 管理应用 | 查看已安装的应用并卸载，可以显示系统应用 |
| 管理表盘 | 查看、删除表盘，把某个表盘设为当前表盘 |
| 设备信息 | 名称、地址、型号、代号、IMEI、固件版本、序列号、电量与存储空间 |
| 分享二维码 | 生成配对信息二维码，可切换「OronBox 码」与「AstroBox 兼容码」 |

## ZeppOS 特色功能

ZeppOS 设备（Amazfit、小米手环 7 等）在「特色功能」里提供更多扩展能力：

- **语音实验室**：采集、监听并回复手表的语音助手会话（如小爱同学）；支持连续采集、把消息返回给手表，采集的数据可以导出为 Opus 或 WAV
- **屏幕镜像**：在当前设备上实时查看手表画面，可调整画面间隔（10–250）
- **离线地图**：选择 ZIP 地图包或 Garmin IMG 文件传输到手表；不超过 2 MB 的包可以用 BLE 传输，更大的建议切换经典蓝牙；传输开始后需要在手表上确认安装
- **应用设置**：查看和管理已缓存的 ZeppOS 应用设置数据，编辑伴生服务（app-side）/ setting 兼容文件
- **应用调试**：在本地脚本运行时中运行缓存的伴生服务（app-side）脚本，用消息编辑器模拟或发送消息到手表，查看调试事件
- **查找设备**：让设备持续振动或响铃，方便在附近找到它
- **音乐同步**：把 MP3 文件传到设备；Vela 设备单个文件不超过 100 MB；ZeppOS 设备不超过 50 MB（建议用经典蓝牙，更快）；可以管理设备歌曲与歌单
- **录音同步**（小米系）：从手表同步并导出录音

## 本地安装资源

「安装应用 / 安装表盘 / 固件更新」都支持从本地文件安装

选择文件后，应用会**按文件内容**判断类型并弹出确认（文件类型不对、平台不匹配时会警告，带 3 秒倒计时，需要手动确认）

详见[资源库](./resources)的「本地文件安装」

## 设备日志

「设置 → 运行日志 → 拉取设备日志」可以从当前连接的小米设备拉取日志

过程可能较长，期间请勿把应用切到后台或关闭设备屏幕
