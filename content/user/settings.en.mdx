The **Settings** tab is organized into categories:

| Category | Contents |
| --- | --- |
| Accounts & authorization | BandBBS / Xiaomi / Huami / GitHub — see [Accounts](./accounts) |
| Appearance & navigation | Language, theme, navigation position, clean mode |
| Connection & downloads | Auto-reconnect, CDN node, install packet interval |
| Queue | Auto-install, keep completed queue items |
| Support & info | Feedback tickets, about, licenses, acknowledgements, website |
| Advanced | Close-button behavior, replay onboarding, developer tools |

## Appearance

- **Language**: change the app language.
- **Theme mode**: follow system / light / dark / OLED dark.
- **Dynamic color**: tint the app with the system accent.
- **Color scheme**: pink, purple, teal, green, red, amber.
- **Navigation position**: where the side tab bar sits on wide screens (bottom / center / split).

## Clean mode

Settings → Appearance & navigation → Clean mode toggles individual features:

- Main navigation: plugin entry, explore entry, inbox
- Home sections: banner carousel, editor sections, home feed, announcement popups
- Resource sources: OronBox, BandBBS, AstroBox, Huami app store
- Community: comments, creator center, BandBBS sign-in, GitHub sign-in

Disabled items disappear from the app.

## Connection & downloads

- **Auto-reconnect**: reconnect the last paired device on startup (off by default; not supported on the web).
- **GitHub CDN**: the node used for GitHub-hosted community indexes (picked automatically by the first-run speed test).
- **Packet interval**: the Bluetooth packet-send delay during installs; usually leave it alone.

## Queue

- **Auto-install**: start installing automatically when a download finishes (on by default).
- **Keep completed items**: don't clear finished install-queue items.

## Feedback tickets

Settings → Support & info → Feedback lets you file problems or suggestions:

- Enter a **subject** and your **message**; the ticket is created on submit.
- Status: open / processing / replied / resolved / dismissed / closed.
- You can read the resolution and keep replying (closed tickets can't be replied to).

## Run logs

Settings → Run logs lets you view, export and manage logs, and pull device logs (Xiaomi devices).

> Logs can contain sign-in credentials. **Don't share them with anyone except the official maintainers.**

## About

- About software: version, changelog, development team, build info.
- Disclaimer: user agreement and liability statement.
- Official website: [oronbox.zxor.org](https://oronbox.zxor.org).
- QQ group: join the community chat.
- Open source licenses and acknowledgements.

## Advanced

- **Close-button behavior**: ask every time / exit / minimize to tray.
- **Replay onboarding**: show the first-run wizard again.
- **DevTools**: enable a separate debug window.
- **Hidden tools → unlock code**: enter the MAC address and serial shown on the device to compute a Xiaomi wearables unlock code. Unlocking can void the warranty or lose data — the app warns you before use.
