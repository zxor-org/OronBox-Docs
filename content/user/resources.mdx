资源库在「探索」标签页，用来搜索、浏览并安装设备资源（表盘、快应用、小程序、固件等）

## 资源源

资源库聚合了多个来源：

| 资源源 | 说明 |
| --- | --- |
| OronBox | OronBox 服务器维护的资源 |
| AstroBox Repo | AstroBox 社区仓库 |
| 米坛社区 | 米坛（BandBBS）资源，部分需要登录米坛账号 |
| 华米应用商店 | 华米商店资源，只提供小程序；只在已连接 ZeppOS 设备时显示 |
| 插件注册源 | 由带相应权限的插件动态注册 |

## 浏览与搜索

- 顶部可以切换**卡片视图 / 列表视图**，米坛与华米源固定为列表视图
- 搜索支持关键词查找
- 点「筛选」可以按条件过滤：
  - **类型**：快应用 / 小程序 / 表盘 / 固件，一次只能选一种
  - **设备 / 分区**：不同资源源有各自的设备或分区 ID
  - **免费**：只显示免费资源，同时隐藏普通付费与强制付费资源
  - **隐藏付费 / 隐藏强制付费**：「强制付费」筛选只在 AstroBox Repo 提供
- 列表滚到底会提示「到底了，看看来自其他源的资源？」

## 资源详情

资源详情页包含：名称、简介、下载次数、版本、更新日志、预览图、支持的设备、资源平台与类型、合集入口（「来自合集 xxx」）、评论区和举报入口；部分资源带「精选」标记

- 评论需要登录米坛账号；评论会经过审核（待审核 / 已删除 / 未通过社区规范）
- 遇到外部链接时，应用会先提示该网站由第三方运营，与 OronBox 无关

## 下载与安装

1. 在资源详情页点「下载」，任务进入下载队列，按钮变为「已在队列」
2. 下载完成后自动开始安装（「设置 → 队列 → 自动安装」默认开启，关闭后需要手动确认）
3. 安装目标是**当前已连接的设备**；安装前会校验资源平台与设备平台：ZeppOS 资源只能装到 ZeppOS 设备，VelaOS 资源只能装到小米 / Vela 设备

下载与安装的进度可以在队列页面查看（下载队列 / 安装队列，支持暂停、开始、清空）

## 本地文件安装

从设备页或安装页选择本地文件时，应用会**先分析文件内容**（按文件头与包结构判断类型，而不是只看扩展名），然后弹出确认：

| 分析结果 | 你会看到 | 选项 |
| --- | --- | --- |
| 无法识别类型 | 「OronBox 无法识别此文件的实际资源类型」 | 取消安装 / 按所选类型继续 |
| 平台不匹配 | 「这似乎是一个 \{平台\} 设备的资源，当前设备不支持安装」 | 我知道了 / 强制安装 |
| 类型不匹配 | 「这似乎是一个 \{检测类型\} 资源，但您选择的资源类型为 \{所选类型\}」 | 取消 / 按所选类型 / 按检测类型 |
| 正常 | 「确认要安装 \{文件名\}（\{大小\}）吗？」 | 取消 / 确认安装 |

- 在「无法识别」「平台不匹配」「类型不匹配继续安装」三种情况下，确认按钮带 **3 秒倒计时**，倒计时结束后需要**手动点击**才执行——倒计时只是让你确认风险，不会自动安装
- 平台不匹配时强行安装可能引发不可预知的问题，只在确认文件来源与设备匹配时使用

## 合集

资源可以被整理进**合集**（创作者创建），合集里会显示资源数量与累计获投硬币数

资源详情页会标明它来自哪个合集；创作者文档见[创作者中心](/creator)

## 投币

投币是支持创作者的方式（需要登录）：

- 硬币来源：**每日签到**，每天可得 1～5 枚硬币
- 在资源详情页点「投币」，可以投 1 颗或 2 颗硬币
- 投币后**无法撤回**；投币有助于资源获得更多展示机会；创作者会获得投币数量 **10%** 的硬币收益
- 你的硬币余额与签到入口在「首页 → 资源投币」

## 纯净模式（功能开关）

「设置 → 外观与导航 → 纯净模式」可以逐个开关各资源源和功能入口（主导航、首页信息流、评论区、创作者中心、华米应用商店等），关闭后对应内容不再显示
