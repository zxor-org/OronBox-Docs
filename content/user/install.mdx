## 系统要求

| 平台 | 要求 |
| --- | --- |
| Windows | Windows 10（64 位）及以上 |
| macOS | macOS 10.15 及以上（Intel 与 Apple Silicon 通用） |
| Linux | 需要已登录的图形桌面环境；发行版不限 |
| Android | Android 7.0（API 24）及以上 |
| Web | Chrome / Edge 等支持 Web Serial 与 Web Bluetooth 的浏览器 |

iOS 目前不支持

## 获取安装包

到[下载页](/download)选择你的平台：

- **Windows**：`.exe` 安装程序，或 `.zip` 压缩包
- **macOS**：`.dmg` 镜像（Intel 与 Apple Silicon 通用）
- **Linux**：`.AppImage`、`.flatpak`、`.deb`、`.rpm`、`.pkg.tar.zst` 或 `.tar.gz`，按发行版选择
- **Android**：`.apk` 安装包；推荐 `arm64-v8a`，32 位设备用 `armeabi-v7a`，模拟器用 `x86_64`
- **Web**：自部署的静态包（`.zip`）

> 下载页的「下载」按钮会自动识别你的系统并给出对应安装包；Linux 用户点击后可以从菜单中选择具体格式

## 首次启动引导

第一次打开应用会进入引导流程，共五步：

1. **欢迎**：介绍 OronBox 的功能（设备连接、资源中心、插件系统、多端适配、完全开源）
2. **用户协议与隐私说明**：需要**滚动到底部**后才能勾选「我已阅读并同意」，不接受协议无法继续使用
3. **可选登录**：可以登录米坛、小米或华米账号，也可以跳过，之后在设置里再登录；小米和华米账号的登录都在本地完成
4. **GitHub CDN 测速**：自动选择最快的下载节点，无需操作
5. **完成**：进入应用

## 桌面端后台服务

Windows / macOS / Linux 桌面端启动后会在后台运行一个服务，统一管理蓝牙连接与任务；图形界面和命令行共用这个服务，不需要手动管理

## 重新引导

想再看一遍欢迎向导，可以在「设置 → 高级」里点「重新引导」
