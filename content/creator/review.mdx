## 审核流程

资源提交后进入 OronBox 审核

审核通过后资源上线，并同步到米坛 / AstroBox（见[发布资源](./publish)）

被驳回的资源会带**审核意见**，修改后重新提交即可

## 资源状态

| 状态 | 含义 |
| --- | --- |
| 草稿 | 还没提交，只有你能看到 |
| 审核中 | 已提交，等待审核 |
| 审核通过 | OronBox 审核通过 |
| 外部审核中 | 已通过 OronBox 审核，正在等待外部平台审核（如 AstroBox 维护者） |
| 审核未通过（打回） | 资源被驳回，界面会列出需要修改的问题，改完重新提交 |
| 已发布 | 审核通过且同步完成后，资源在商店可见 |
| 已下架 | 资源从商店隐藏，可恢复 |
| 已冻结 | 被管理员冻结，内容不可修改，仅管理员可解除 |
| 发布失败 | 同步到外部平台失败 |
| 已被新版本取代 | 该版本已被更新的版本取代 |
| 已取消 | 提交被取消 |

## 审核通过后

- 资源在商店可见，用户可以下载、投币
- 你可以在工作台**更新资源**（发布新版本）、**下架**或**恢复上架**
- 资源状态变化（如管理员下架）会给出原因说明

## 被管理员处理

- **管理员下架**：资源被下架并说明原因；你可以修改后重新提交审核，审核通过后自动恢复上架
- **管理员冻结**：内容不可修改，仅管理员可解除冻结；冻结期间资源不可编辑、不可提交

## 合集审核

合集信息同样需要审核：状态为「合集信息待审核」或「已公开」
