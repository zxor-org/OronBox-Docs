创作者中心是 OronBox 面向资源作者的板块：在这里发布表盘、快应用等资源，管理它们的状态，把资源整理成合集，并获得用户的硬币

## 开通条件

创作者中心需要**登录米坛账号并连接 OronBox 账号**

首次进入时会要求：

1. 阅读并同意**米坛社区条款和规则**与 **AstroBox-Repo 投稿规范**
2. 授权 OronBox 代表你发布米坛资源（米坛写入授权）
3. （可选）连接 GitHub 账号，用于以自己的账号发布 AstroBox 资源

未登录时入口会提示「登录后使用创作者中心」

## 工作台

创作者中心包含：

- **我的资源**：草稿 / 审核中 / 已发布 三个列表
- **资源合集**：把同类型资源整理为合集卡片
- **创作激励**：累计获投硬币、近 14 天获投
- **导入外部资源**：从米坛 / AstroBox 导入你已有的资源（实验性）

## 你能做什么

- [发布资源](/creator/publish)：按向导一步步创建、提交审核、发布到 OronBox / 米坛 / AstroBox
- [审核状态](/creator/review)：了解审核流程与各状态的含义
- [合集](/creator/collections)：把同类资源整理为合集
- [投币机制](/creator/coins)：签到、获投与收益规则
- [推荐机制](/creator/recommend)：资源如何获得更多展示机会
- [限制](/creator/limits)：名称、图片、文件等要求

## 账号被封禁 / 冻结

- **账号被封禁**：无法使用创作者中心，需通过工单联系管理员
- **创作者功能被冻结**：暂时无法提交或管理资源，账号其它功能不受影响

相关：投币规则见[资源库 - 投币](/user/resources)
