## 新建资源

在创作者中心点「新建资源」，进入发布向导，共六步：

1. **基本信息**：资源标识（slug）、资源名称、资源简介；可以随时「保存草稿」
2. **资源文件**：添加安装包（Vela 快应用或表盘文件）；支持添加多个文件，上传后可以重新上传
3. **选择设备**：为资源绑定支持的设备
4. **设备-文件映射**：确认每个设备分区对应的安装包；如果同一米坛分区绑定了多个安装包，或无法确定某个设备的米坛分区，向导会提示你调整
5. **发布目标**：选择发布到哪里（见下文「发布目标」）
6. **发布预览**：确认信息后「提交审核」

向导中还可以设置：

- **图标与封面**：图标 1:1、封面 3:2；OronBox 可选，**AstroBox 必选**；图片使用 PNG / JPEG / WebP
- **内容属性**：原创 / 二创 / 移植 / 模板换皮 / AI 辅助 / AI 生成
- **创作者与来源**：联合创作者（邀请米坛用户）、原作者、来源链接、许可协议、授权说明
- **附加链接**：给资源添加外部链接（名称 + 地址）

## 发布目标

资源可以同时发布到多个目标：

| 目标 | 说明 |
| --- | --- |
| OronBox | **必选**，资源需经过 OronBox 审核 |
| 米坛 BandBBS | 需要米坛写入授权；OronBox 审核通过后，会以该资源信息**直接发布到米坛对应分区** |
| AstroBox Repo | 需要连接 GitHub；OronBox 审核通过后，会创建资源分仓库并向 AstroBox 官方仓库**提交 PR**，由 AstroBox 维护者独立审核 |

提交确认时会显示「提交至 OronBox」「同步至米坛：分区名」「同步至 AstroBox：仓库名」

## 提交后会发生什么

- OronBox 审核通过后，资源上线；同步到米坛 / AstroBox 的目标随后生效（AstroBox 还需维护者审核 PR）
- 资源发布后可以在工作台里「更新资源」（新的安装包与预览图会沿用，无需重新上传），并查看**版本历史**
- 已关联米坛 / AstroBox 的资源，后续更新会**同步到米坛 / AstroBox**

## 下架与删除

- **下架**：资源从商店隐藏，可随时恢复上架
- **删除**：
  - 草稿：永久删除，无法恢复
  - 已发布的 OronBox 资源：会**同步删除对应的米坛资源**，无法恢复
  - AstroBox 上已发布的内容不受删除影响，如需下架请联系 AstroBox-Repo 维护者

## 原理

一句话总结：**OronBox 是你的资源在 OronBox、米坛、AstroBox 三个平台上的统一发布入口**

内容在 OronBox 审核通过后，自动同步到米坛分区（发帖）与 AstroBox（PR），你不用分别去三个平台操作

审核规则见[审核状态](./review)
